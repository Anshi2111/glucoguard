## 🎨 Color Usage Guide

| Element | Color | Usage |
|---------|-------|-------|
| Background | #0d1117 | Main page background |
| Cards | #1a2332 | Card/panel background |
| Text | #e1e8ed | Primary text |
| Accent | #00d9ff | Important numbers, highlights |
| Success | #2df890 | Status OK, checkmarks |
| Warning | #ffa726 | Alerts, cautions |
| Error | #ff4757 | Errors, dangers |
| Muted | #7a8694 | Secondary text |
| Border | #2d3e54 | Dividers, borders |
